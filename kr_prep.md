# Подготовка к контрольной работе

## Когда использовать merge и rebase
Merge выбираю для общих веток: он сохраняет историю. Rebase использую для своей локальной ветки, чтобы перенести изменения на актуальный main.

## Почему нельзя делать rebase публичной ветки
Rebase меняет хеши коммитов. У коллег останется старая история, поэтому при синхронизации возможны дублирование коммитов и конфликты.

## Зачем нужен multi-remote
Он позволяет хранить копию проекта на другом сервере. Это полезно для резервного копирования и переноса проекта между GitHub и GitLab.
